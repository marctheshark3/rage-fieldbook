# Publication note

- **Audience and useful lesson:**
- **Selected files:** Exact publication set, including generated outputs.
- **Public sources:** Anonymous-accessible URLs and inspected revisions.
- **Authorship and attribution:** Original work, shared work, upstream contribution, and format inspiration.
- **Rights:** What is linked, what is reproduced, and what permission applies.
- **Concrete claims:** Evidence and limitation for each consequential statement.
- **Private-derived questions:** Any general lesson rewritten with a public or clearly fictional example.
- **Boundary review:** No private source, repository inventory, conversations, logs, credentials, endpoints, customer data, or unreleased project specifics.
- **History review:** Exact tracked files and commits inspected before publishing.
- **Validation:** Commands run and their actual results.
- **Outstanding limitations:** Checks not performed and claims not independently reproduced.

Keep private research and its identifiers outside the publication destination. An automatic scan supplements editorial review; it does not establish that every possible disclosure has been excluded.
